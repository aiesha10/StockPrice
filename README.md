*StockPrice – Stock Price Prediction Using LSTM*

A Python project that predicts future stock prices based on historical data using LSTM (Long Short-Term Memory) neural networks. This project uses Apple Inc. (AAPL) stock data as an example.

*Features*

Collect historical stock data from Yahoo Finance using yfinance.

Preprocess data using MinMaxScaler.

Split data into training and testing sets.

Build a stacked LSTM model for time series prediction.

Predict future stock prices (e.g., next 30 days).

Visualize historical and predicted stock prices with Matplotlib.

*Technologies Used*

pandas – Data manipulation

numpy – Numerical operations

yfinance – Stock data download

matplotlib – Data visualization

scikit-learn – Data preprocessing (MinMaxScaler)

tensorflow / keras – Building and training LSTM models
